## 结论

1. **`(23,21)` 在中间态符号仍是负的**：`prior = −0.4497`，signed rank **96/108**；它不是“到中间态才翻正”的普通状态依赖像素。
2. **它的幅值确实很大**：初始 `|prior|` 排名 **10/108**，中间态 **14/108**。这支持“幅值 `|grad_eps|` 能标记强耦合核心像素”的判断。
3. **一阶符号不可盲信**：在 Δε≈10 的大翻转下，`(23,21)` 的负号把 signed ranking 打到 96/108；纯伴随或 signed prior 都不会选它。下一步应使用 `|grad_eps|` 作为核心候选筛选，再对高幅值像素做双向探索（flip 0→1 与 1→0 都要试），不能只用 `linear_prior` 符号排序。
4. `(15,12)` 在中间态是 signed rank 1（prior +0.5643），说明中间态确实存在可用的正梯度像素；但 baseline 的关键翻转是 `(23,21)`，不是它。
