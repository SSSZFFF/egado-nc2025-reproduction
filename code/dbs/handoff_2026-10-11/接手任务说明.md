# 接手任务说明

请先完整阅读同目录《两方案DBS_跨电脑操作指南.md》，然后在本机对两个方案分别进行光学 DBS，并提交可复现比较结果。

共同输入是 `inputs/common/2mode_final.npz`，这是已完成的 3.6 μm×3.6 μm 两模 TO，不需要重新 TO。方案 A 使用 `inputs/A_D0`，D=0 边缘候选固定为 238 格，其余数字格固定。方案 B 使用 `inputs/B_curve_DRC120`，候选固定为最终 108 格，格外连续曲线必须保留；它不能被改成全 900 格结构。

先执行离线输入核验，在本机配置同版 SP90 公共规则、重跑 B 初值 DRC，再对接统一 FDTD 模型。包内模板尚未在准备电脑上通过 Lumerical 执行，完整光学 DBS 接口需你实现并试运行。请先确认材料、数组方向、端口、所选 TE₀/TE₁ 模式和模式展开评分，完成初值两源评估和重复性测试后再长时间运行。

两个主比较实验按 `config/experiment.json` 使用相同光学目标和扫描/停止规则，只在冻结候选集上做 DBS，采用相同 `audit_only` DRC 审计策略。目标函数为上端输入到输出 TE₀、下端输入到输出 TE₁ 的带内目标透射平均；每次结构评估运行两个源并保存完整 2×2 模式透射谱。不得把普通功率监测器总透射当成目标模式透射。

为了保留 B 的制造要求，从同一个合法 B 初值再按 `config/B_strict.json` 运行制造约束版：每个试探结构先通过完整公共 DRC 与额外 120 nm Si 线宽/间距检查，再做光学判优。单独保存 B_strict；不要混用两种门禁条件宣称仅候选数不同。若没有合法且改善性能的单格翻转，如实报告停止，不自行扩大候选区域。

请按指南保存逐格历史、断点状态、输入及配置 SHA、实际 forward 求解次数、完整光谱、最终 GDS/FSP、实际 DRC 报告和更细网格复核。比较图要同时包含 FoM 对真实求解数和实际时间，报告两通道插损、串扰、带宽及最终违规情况。

当前交接包仅验证了几何：A 的中心采样二值初值有 22 个公共规则标记，B 初值为 0；没有两组光学 DBS 的结果。完成工作前不要推断 B 的光学性能或真实加速比。遇到失败，先查具体模型、求解或数据问题，保留失败日志和已完成结果。
