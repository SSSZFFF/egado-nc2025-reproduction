# 两种提取方案的 DBS 交接包

先读 [详细操作指南](06_两方案DBS_跨电脑操作指南.md)。给接手人的任务文本见 [接手任务说明](07_接手任务说明.md)。

本包对应同一份两模 TO：A 为 D=0 的 238 格，B 为连续曲线经过 DRC 和接缝修复后的 108 格。A 的非候选数字格固定；B 的候选区域以外曲线固定。

包内含检查点、两组候选掩码/坐标/初始状态、完整和固定背景 GDS、几何检查记录、统一模型模板及跨电脑核验工具。**尚未运行光学 DBS；统一模型模板也需要在目标电脑先试运行。** 完整 FDTD—DBS 接口需接手人按指南实现。

主比较让 A/B 使用相同光学设置、目标函数与 DBS 规则，同时审计制造违规。若 B 最终需要保持制造要求，另跑 B_strict，并单独报告，避免混用约束条件。

将完整目录复制到另一台电脑，安装几何依赖后执行：

```text
python tools/geometry_io.py verify
```

该命令不启动 FDTD。预期 A=238、B=108，交集 106；B 初值额外 120 nm width/space=0。实际公共 DRC 的初始核验：A 为 22 个标记，B 为 0，均执行 248 类规则。目标电脑应根据指南配置同版 PDK 并重新核验。

不要选用历史的 74、79、97 或 206 格。不要直接运行旧 `main.py` 的全阵列 DBS，也不要把 B 全部改成 900 个方格。

`inputs` 和原始配置作为基准保留；新配置、新报告、FSP 和优化结果放到自己的 `results` 目录。历史留档中的绝对路径指向准备电脑，新工具以交接包目录定位输入。
