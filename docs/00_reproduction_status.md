# EGADO（Nat. Commun. 2025）复现状态

更新时间：2026-11-24  
论文：Sun, A., Xing, S., Deng, X. et al. *Edge-guided inverse design of digital metamaterial-based mode multiplexers for high-capacity multi-dimensional optical interconnect.* **Nature Communications 16, 2372 (2025)**. DOI: [10.1038/s41467-025-57689-7](https://doi.org/10.1038/s41467-025-57689-7)

---

## 1. 先给结论

**没有完成论文级完整复现。** 当前是“部分复现 + 子器件推进”：

- 两模平台：TO、EG-ATD 索引映射、数字 DBS 链路已打通；严格版数字器件 J = 0.8864，DRC 合规，但未达到项目自设的 J ≥ 0.92。
- 四模器件：TO 和受限 DBS 完成，平均插损 1.404 dB 与论文 Table 1 的 1.24 dB 接近，但最差串扰约 −14.3 dB，明显差于论文的 −18 dB；最终 DRC 报告未归档。
- 五模器件（论文主结果）：只完成 TO 的中间状态，参数未充分二值化，没有五模数字版图和 5×5 传输谱，**不能称为复现**。
- 论文的流片与实测部分（四/五/六模器件、324 Gb/s、38.2 Tb/s）没有复现：本仓库没有流片和实验测量数据。

## 3. 两模：复现得最完整的一块

### 3.1 TO 阶段

来源：`code/two_mode/analysis-2mode/2mode_convergence.txt`、`2mode_final.npz`，以及 `docs/03_改进方案_专家评估说明.md` 的复核。

| 项目 | 数值 |
|---|---:|
| 设计区 | 3.6 × 3.6 μm² |
| 数字像素 | 120 nm，30 × 30 = 900 格 |
| 保存的介电常数数组 | 181 × 181 |
| 收敛记录 | 249 条（0–248） |
| 最终 β | 708.801874985 |
| 投影后 discreteness | 0.991363323 |
| 两通道 ModeMatch 得分之和 | 1.965973502 / 2.0 |
| 等效插损 | 0.025 dB / 0.125 dB |

补充说明：`ModeMatch(norm_p=2)` 的日志得分不是严格的“11 个波长点平均透射率”。`ΣT ≈ 1.966` 只能作为近似描述；正式比较应分别保存目标函数得分和真实目标模透射谱。

### 3.2 EG-ATD 索引映射

| 膨胀系数 D | 直接沉积 Si | 直接刻蚀 | TBD | 未分类 | 直接转换率 | 两模数字阶段理论求解次数 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 562 | 100 | 238 | 0 | 73.56% | 952 |
| 2 | 519 | 73 | 308 | 0 | 65.78% | 1232 |
| 4 | 480 | 55 | 365 | 0 | 59.44% | 1460 |

论文 Supplementary Note 5 在 D = 0 时的直接转换率为 71.22%；本实现 73.56%，同一量级，支持索引映射逻辑复现合理。

### 3.3 两模数字 DBS

| 结构 | J | 上输入 → TE0 | 下输入 → TE1 | 平均插损 | 最差串扰 | DRC |
|---|---:|---:|---:|---:|---:|---|
| A_D0（D=0 候选） | 0.898436 | — | — | — | — | **38 违规** |
| B_strict（最终严格版） | **0.886449** | 91.53% | 85.76% | 0.384 / 0.667 dB | −16.62 / −19.51 dB（频点最差） | 248 类公共规则 0 违规；120 nm Si 检查 0 违规 |
| B_stage2（联合两格动作） | 0.886449 | 91.53% | 85.76% | 0.384 / 0.667 dB | 同上 | 248 类公共规则 0 违规；120 nm Si 检查 0 违规 |

关键事实：

- B_strict 与 B_stage2 的 `final_state.npz` 完全相同，光谱逐元素差异约 3.11e−15，可视为同一状态的重复保存。
- Stage 2 只枚举了 119 个 4 连通相邻格对的单一互补动作，49 个动作完成 FDTD，最大正差 8.1e−5 < 1e−4 接受阈值。它**不能证明全局最优或物理极限**。
- 原始 B（未做 108 格约束）J = 0.92484，但公共 DRC 有 103 处标记，不能作为可制造结果。
- B_strict 的 DRC 结论只覆盖 `V0.9.0 KLayout common rules`（248 类）加 supplemental 120 nm Si 线宽/间距检查；不是完整 foundry deck、Calibre sign-off 或“可直接投片”。

| DBS 轮次 | 3 轮 × 161 候选格 |

对照论文 Table 1 的四模结果：IL 1.24 dB、CT −18 dB。本地 IL 与论文相差约 0.16 dB，但串扰差约 4 dB，且本结果只是常数折射率模型下的 20 nm 网格仿真，没有论文的实测数据支撑。

注意：`final_tapeout_120nm.gds` 已导出，但结果目录中没有最终公共 DRC 报告。DBS 过程中每个接受状态都经过在线 DRC 门禁，但这不等于对最终导出 GDS 完成了独立签核。因此当前只能称为“候选版图”。

## 5. 五模：论文主结果尚未开始数字阶段

- 本地 `parameters_69.npz`：原始设计参数 discreteness = 0.6254764，投影后介电常数 discreteness = 0.6479496。两者对应不同变量，均未达到 0.99。
- 没有五模的 EG-ATD 输出、DBS 初始态、最终 GDS 或 5×5 模式传输矩阵。
- `upstream/EGADO-main/demo.fsp` 是作者提供的成品器件演示，不是本项目的复现结果；本仓库未收录该 49 MB 文件。
- 论文五模实测 IL 2.96 / 3.62 / 2.43 / 3.94 / 3.10 dB，CT −21.73 / −20.72 / −21.91 / −23.43 / −24.51 dB（1550 nm）。

结论：**五模主结果不能宣称复现。**

## 7. 复现边界

1. **没有流片、没有实测。** 所有结果均来自 Lumerical FDTD 数值仿真；论文的实验部分不在本仓库范围内。
2. **五模未完成。** 两模/四模结果不能外推为五模结论。
3. **DRC 不是完整 foundry 签核。** 只执行了公共 248 类规则和 supplemental 120 nm Si 检查。
4. **四模最终 DRC 未归档。** 不能称“可直接投片”。
5. **脚本保留历史绝对路径。** 需要按本机环境修改；这是研究档案，不是即开即用的软件包。
