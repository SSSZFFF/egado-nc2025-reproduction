## 2.0 补充（2026-10-09）：TBD 判据的物理含义修正

论文原文（Supplementary Note 1B）在引入池化时的动机是：

> "Due to the small pixel size of the analog pattern (20 nm×20 nm in this design) relative to
> the significantly larger pixel size required for the target digital pattern (120 nm×120 nm),
> **a pooling operation is required to adjust the pixel dimensions**"
>
> "Direct mapping of the index is only performed **if the corresponding region in the analog
> pattern consists entirely of non-edge pixels**; otherwise, the pixel state is labeled as TBD"

因此 TBD 判据处理的是 **20 nm → 120 nm 降采样时的量化/数字化歧义**：

> 一个 120 nm 的数字像素若横跨材料边界，则无论赋成 Si 还是 SiO₂ 都会引入表示误差，
> 这种像素才交给 FDTD 决定。

**它不是在判断"这里是否违反 foundry DRC"。** 本文档原先把问题定义为
"位于边界是否意味着制造违规"，该前提应当撤掉。

修正后的问题表述：

$$\boxed{\text{能否直接度量 quantization ambiguity，而不是用 Canny edge 作为 proxy？}}$$

## 1. 背景：EGADO 流程与它的计算瓶颈

### 1.1 三段式流程

论文（Sun et al., *Nat. Commun.* **16**, 2372 (2025), DOI 10.1038/s41467-025-57689-7）的方法：

```
① 拓扑优化 TO          20 nm 网格，连续介电常数 ρ∈[0,1]，伴随法梯度 + L-BFGS-B
                       ↓
② 索引映射（数字化）     Canny 边缘检测 → 最大池化 20nm → 120nm → 三分类
                       ↓
③ 逐像素二值搜索        只对 TBD（to-be-determined）边缘像素，各跑 Si / SiO₂
                       两次 FDTD，取 FoM 更优者
```

### 1.2 第 ② 步的精确机制（论文 Supplementary Note 1B）

设模拟像素边长 $P_A = 20$ nm，数字像素边长 $P_D = 120$ nm：

1. 对归一化介电常数图做 **Canny** 边缘检测，得边缘图 $E(x,y)\in\{0,1\}$
2. **最大池化**：核为全 1 矩阵，**核尺寸 $= S_{AD} + D$**，**步长 $= S_{AD}$**，
   $D>0$ 时边缘图外加**宽度 $D/2$ 的 padding**
   （$S_{AD}$ = 缩放因子；代码实现为 $S_{AD}=P_D/P_A=6$。
   论文正文写 $S_{AD}=P_A/P_D=1/6$，但紧接着把它当步长使用，应为笔误）
3. 池化后二值化：**窗口内只要含任一边缘像素，该数字像素即标为 TBD**
4. 非 TBD 像素直接取模拟图案对应中心值映射

论文把 $D$ 称为**膨胀系数（dilation coefficient）**，$D$ 越大 → TBD 越多 → 直接转换率越低。

### 1.3 代码实现（`func_get_conversion_matrix.py`）

```python
scale = int(pixel_size / mesh_size)            # = 6，即 S_AD
decision_area = scale + buff                   # 核 = S_AD + D
conv_result = convol(edge_img, decision_area, scale, buff // 2)
#                          ↑核大小        ↑步长   ↑padding = D/2
mapped = pattern_mapping(analog_pattern, conv_result, 0.5, scale)
```

与论文逐条一致（`buff` 即论文的 $D$）。

### 1.4 计算瓶颈

论文给出的 Maxwell solve 计数：

$$N_{\text{solve}} = 2M\left[N_A + (1-C)N_P\right]$$

其中 $M$ = 模式数，$N_A$ = TO 迭代数，$N_P$ = 数字像素总数，$C$ = 直接转换率。

第三阶段每个 TBD 像素需要 2 次 FDTD（Si / SiO₂ 各一次）。
**因此数字阶段的代价正比于 TBD 像素数**，减少 TBD 是本方法的核心杠杆。

## 2. 问题：edge 判据隐含的两个未经验证的假设

EGADO 用"是否位于材料边界"作为代理量（proxy）。这隐含两个假设：

**假设 A：位于边界 ⟹ 存在制造问题**
→ 若该边界处的结构尺寸本来就满足最小特征尺寸（MFS），则不存在制造问题。

**假设 B：位于边界 ⟹ 光学上值得优化**
→ 若该处对 FoM 不敏感，则翻转它没有收益。

论文自身的实验**间接支持**这两个假设值得怀疑：作者把 $D$ 从 0 增到 4（TBD 从少到多），
观察到"**扩大 TBD 像素数量并没有带来明显的性能提升**"
（原文：*"expanding the number of TBD pixels does not obtain significant performance improvement"*）。

即：更多 TBD $\nRightarrow$ 更好。本文进一步追问：**EGADO 现有的 TBD 里，有多少是必要的？**

## 3. 提议的方法

### 3.1 核心：把候选集定义从"几何位置"换成"对约束的贡献"

**EGADO：**
$$\text{pixel } i \in \text{TBD} \iff i \text{ 是边缘像素}$$

**本方法：**
$$\text{pixel } i \in \mathcal{C} \iff \text{翻转 } i \text{ 能够减少制造违规}$$

后者不需要预先做边缘检测 —— 制造规则关心的是"solid / void / gap 有多宽"，
而不是"这里是不是一条边"。

### 3.2 制造违规的度量

先定义二值图案 $B(x,y)\in\{0,1\}$（1 = 硅）。用**形态学开运算**表达最小特征尺寸规则：

$$\text{thin}_{\text{Si}}(B) = B \setminus \text{open}(B, \mathcal{D}_{r}), \qquad
\text{thin}_{\text{ox}}(B) = \bar{B} \setminus \text{open}(\bar{B}, \mathcal{D}_{r})$$

其中 $\mathcal{D}_r$ 是半径 $r = \text{MFS}/2$ 的圆盘结构元。总违规面积：

$$\boxed{D(B) = \left|\text{thin}_{\text{Si}}\right| + \left|\text{thin}_{\text{ox}}\right|}$$

（$D=0$ 表示完全满足 MFS 规则。）

### 3.3 候选像素判据

对每个数字像素 $i$，把对应区域分别强制设为硅 / 氧化物，得到 $B_i^{1}$、$B_i^{0}$：

$$\Delta D_i = D(B) - \min\left(D(B_i^{0}),\; D(B_i^{1})\right)$$

$$\boxed{\mathcal{C} = \{\, i : \Delta D_i > 0 \,\}}$$

即：**"翻转这个像素能够减少制造违规"** 才进入候选集。

复杂度：$2N_P$ 次几何运算（形态学开运算 + 连通域），**不需要任何 FDTD**。
在 180×180 网格上单次约 1 ms，全扫 900 像素约 2 s。

### 3.4 可选：词典序（lexicographic）规则

制造规则是硬约束，光学 FoM 是软目标。因此对 $i\in\mathcal{C}$：

| 情形 | 处理 | FDTD |
|---|---|---|
| $D_i^{0} < D_i^{1}$ | 直接选**氧化物** | 0 次 |
| $D_i^{1} < D_i^{0}$ | 直接选**硅** | 0 次 |
| $D_i^{0} = D_i^{1} < D(B)$ | 两态同等合法，需光学判优 | 2 次 |

### 3.5 与 edge 判据的逻辑关系（重要）

两种判据回答的是**同一个问题**："哪些像素值得进入昂贵的后续优化"。
因此它们应当是**替代关系**，而不是简单串联：

- 若取 $\mathcal{C}\cap E$，则额外引入了假设"只有同时是边缘的违规像素才允许优化"
- 该假设未必成立。反例：一个孤立的过小硅岛，其**内部**像素被翻转为氧化物即可消除违规，
  但内部像素并非 Canny 边缘

### 4.5 关于 §3.4 词典序规则的实测

51 个候选**全部**存在明确的 DRC 赢家（$D_i^{0}\ne D_i^{1}$），即理论上可以 0 次 FDTD 决定。

**但本文认为这一结果不可直接采用**，原因见 §6.4：判定裕度极小（1–4 个网格）。

### 4.6 一个必须如实报告的发现

$$\mathcal{C} \subseteq E \quad(\text{即 } |\mathcal{C}\setminus E| = 0)$$

**在本器件上，所有可制造性候选像素同时都是 Canny 边缘像素。**

这带来两点：

- **好消息**：EGADO 的方法**没有漏掉任何一个**真正需要修复的像素
- **需要澄清的地方**：在本器件上，本方法等价于"把 EGADO 的边缘候选集按制造相关性剪掉 79%"，
  而不是一个完全独立的判据。要证明二者确实可以分离，需要找到 §3.5 中那种
  "违规区域内部像素也能修复" 的案例（本器件未出现）

## 6. 局限与风险（如实列出）

### 6.1 最大风险：光学性能未验证

本文只证明了候选集可以大幅缩小，**完全没有验证**剪掉这些像素后的器件性能。
理论上存在两种可能：

- 乐观：那 187–314 个像素确实对 FoM 无影响（论文的 $D$ 实验结果支持这一预期）
- 悲观：其中一部分虽然不是 DRC 违规，但是**光学关键边界**，剪掉会导致插损/串扰明显恶化

**这是决定方法成立与否的唯一关键实验，目前缺失。**

### 6.2 本器件上判据退化为"剪枝"

见 §4.6：$\mathcal{C}\subseteq E$。方法的新意在本器件上体现为"剪枝"而非"替换判据"。
需要一个反例器件来证明二者可以分离。

### 6.3 DRC 规则集不完整

本文只实现了 minimum feature size（一条规则）。
制造上还有 minimum gap、curvature、minimum area、minimum enclosed area 等
（Hammond 2021 的五条）。规则集不完整会**高估**可剪枝的比例。

### 6.4 词典序规则过于激进

51 个候选的 DRC 判定裕度仅 1–4 个网格，例如：

```
cell(0,22)   D_oxide=472   D_silicon=476   →  选 oxide
cell(0,24)   D_oxide=473   D_silicon=472   →  选 Si
```

靠这种量级的差值完全无视光学性能做硬决定，鲁棒性存疑。
建议：DRC 只用于定义候选集与排序，仍需一次最终 FDTD 验证；
或保留光学敏感度最高的 top-$k$ 作为真正的 TBD。

### 6.5 单一器件、单一 TO 结果

全部结论来自**一个器件、一条 TO 轨迹**。统计上不充分。
需要 4 / 5 / 6 模器件与多次随机初值的重复实验。

### 6.6 未使用的第二个筛选轴

"可制造性"只回答"值不值得修"，不回答"修了光学上划不划算"。
完整方法需要第二轴：TO 最后一轮的伴随梯度

$$G_i = \left|\frac{\partial F}{\partial \rho}\right|_{\Omega_i}$$

⚠️ 但需注意：$G_i$ 是连续变量的小扰动梯度，而后续操作是 120 nm 的有限幅度二值翻转，
二者量纲不同，$G_i$ **只能作为排序指标，不能当作实际性能变化**。

### 6.7 与基线不完全可比的细节

- 我们的 TO 用了 20/20/**20** nm 网格，论文 TO 阶段为 20/20/**44** nm
- `min_feature_size = 0`（lumopt 官方 DFM 阶段关闭），与论文一致
- 上述差异意味着我们的 TO 图案与论文不完全相同（我们的更"简洁"），
  但直接转换率 73.56% vs 论文 71.22% 表明量级一致
